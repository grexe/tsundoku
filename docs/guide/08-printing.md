# Printing and file info

## Printing

**File > Print** (Cmd+P) asks for the range of pages, even or odd pages only, and the order (in order or reversed). **File > Page
setup** sets the paper. Printing uses the print server of Haiku, so any printer that is set up works, and so does the PDF Writer.

## File info

**File > File info** shows what the file says about itself: the title, author, subject, keywords, the program that made it, the
dates, the number of pages and, for books and comics, the cover, series, publisher and so on, and whether the document may be
printed, copied and edited.
