# Selecting, copying and searching

## Selecting text

There is no mode to switch: hold **Option** (or Alt) and drag, and the selection follows the text. The selected text is copied
at once, so you can paste it into any program. The pointer becomes an I-beam while Option or Cmd is held.

- **Double click** selects a word, **triple click** a line.
- **Option+Shift+drag** selects a rectangle; that also copies the picture of the area.
- A selection can run over **several pages** (in the continuous flow, or over the two pages of a spread). It is copied page by
  page.
- A selection stays when you zoom or rotate.
- Dragging without a key still moves the page. The secondary mouse button opens a menu with Copy, Select all and the link
  actions; drag the secondary button to drag the selected text or picture into another program.

**Edit > Select all** (Cmd+A) selects the text of the page, **Select none** (Cmd+Shift+A) lets go.

## Searching

**Search > Find** (Cmd+F) asks for a word or phrase. Toji finds the text in the order of reading, shows **all hits on the page**
and goes to the first one. **Find next** (Cmd+G) continues after the previous hit and **Find previous** (Cmd+Shift+G) goes
backwards.

## Text in scanned documents

A scanned page is a picture. Documents that have a text layer (many PDF files and DjVu documents do) can be searched and
selected like any other; for a document without one there is nothing to find.
