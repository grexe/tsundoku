# Keyboard and mouse

## Keyboard

| Key | Action |
|---|---|
| Cmd+S, Cmd+Shift+S | Save, Save as |
| Cmd+R | Reload |
| Cmd+P | Print |
| Cmd+W, Cmd+Q | Close, Quit |
| Cmd+Z, Cmd+Shift+Z | Undo, Redo |
| Cmd+C | Copy |
| Cmd+A, Cmd+Shift+A | Select all, Select none |
| Cmd+Shift+H, U, K | Highlight, underline, strike out the selection |
| Cmd+Shift+N | Add a margin note to the selection |
| Cmd+F, Cmd+G, Cmd+Shift+G | Find, Find next, Find previous |
| Cmd+J | Jump to a page |
| Cmd+Left, Cmd+Right | Back, Forward (through places you jumped from) |
| Cmd++, Cmd+- | Zoom in, Zoom out |
| Cmd+/, Cmd+* | Fit to page width, Fit to page |
| Cmd+T, Cmd+Shift+T | Larger text, Smaller text (books) |
| Cmd+1 ... Cmd+4 | Sidebar: bookmarks, page list, attachments, annotations |
| Cmd+H | Hide or show the sidebar |
| Cmd+M | Show error messages |
| Escape | Cancel a tool, let go of a selection |

## Mouse

| | |
|---|---|
| Drag | move the page |
| Option+drag | select text |
| Option+Shift+drag | select a rectangle (copies the picture, too) |
| Double click, triple click | select a word, a line |
| Middle button, drag | zoom to a rectangle |
| Secondary button | menu: copy, select all, mark, add, link actions |
| Wheel | scroll |
